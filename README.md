# summon

Пароли и ключи нужны приложению при запуске, но хранить их в репозитории вместе с настройками не стоит. summon читает ссылки на секреты из `secrets.yml`, получает значения из хранилища и передаёт их запущенной команде через переменные окружения.

## Возможности

- Читать `secrets.yml` с именами переменных окружения и ссылками на секреты.
- Получать секреты через встроенный провайдер Conjur или отдельно установленный провайдер.
- Передавать полученные значения в окружение дочернего процесса.
- Записывать секреты в файлы с помощью механизма push-to-file.
- Выбирать провайдер явно через аргумент `--provider`.

## Установка

Понадобится Go версии, указанной в `go.mod`. Из корня исходников выполните:

```sh
go mod download
go install ./...
```

Go установит исполняемые файлы в `GOBIN`, если эта переменная задана, иначе в каталог `bin` внутри `GOPATH`. Для стандартной настройки добавьте его в `PATH`:

```sh
export PATH="$(go env GOPATH)/bin:$PATH"
summon --help
```

Встроенный провайдер Conjur не требует отдельного исполняемого файла. Для другого хранилища установите подходящий провайдер отдельно.

## Использование

Создайте `secrets.yml`:

```yaml
DB_PASSWORD: !var production/db/password
API_KEY: !var production/api/key
```

Здесь `production/db/password` и `production/api/key` обозначают пути к секретам в Conjur. Учётная запись должна иметь право читать эти значения.

Настройте подключение и аутентификацию. Замените адрес, имя организации и данные учётной записи своими значениями:

```sh
export CONJUR_APPLIANCE_URL=https://conjur.example.com
export CONJUR_ACCOUNT=myorg
export CONJUR_AUTHN_LOGIN=host/myapp
export CONJUR_AUTHN_API_KEY='replace-with-your-api-key'
```

Запустите приложение, которое читает `DB_PASSWORD` и `API_KEY` из окружения:

```sh
summon --provider conjur -f secrets.yml ./myapp
```

`./myapp` здесь обозначает исполняемый файл вашего приложения. summon получит секреты и добавит их в окружение этого процесса. Окружение родительской оболочки от такого запуска не изменится.

**Не выводите секреты в журналы.** Проверка через `env` или отладочная печать переменных может раскрыть полученные значения.

В примере провайдер выбран явно. Без `--provider` summon использует единственный исполняемый файл в каталоге провайдеров; если файлов несколько, просит указать провайдер. При пустом каталоге используется встроенный Conjur.
